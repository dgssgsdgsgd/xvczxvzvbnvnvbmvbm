## Как получить API-ключ

1. Перейдите на сайт [exchangerate-api.com](https://www.exchangerate-api.com/)
2. Зарегистрируйтесь, указав ваш email и создайте аккаунт.
3. После регистрации вы получите бесплатный API-ключ.
4. Скопируйте ключ и вставьте в переменную `API_KEY` в вашем коде.

**Обратите внимание:** бесплатного тарифа обычно достаточно для учебных целей и небольшого использования.

## Примеры использования и тесты

- После запуска программы откроется графический интерфейс.
- Введите сумму, выберите валюту "из" и "в".
- Нажмите кнопку "Конвертировать" — в окне появится результат.
- История операций будет отображаться ниже.

### Тестовые сценарии:

1. Введите `100`, выберите "USD" -> "EUR", нажмите "Конвертировать" — результат и история появятся.
2. Введите `-50`, выберите любые валюты — появится сообщение об ошибке.
3. Введите не числовое значение, например, `abc` — появится сообщение об ошибке.
4. Проверьте работу с различными валютами при обновлении курса.
